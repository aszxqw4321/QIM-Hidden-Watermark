这是一个纯前端运行的图片盲水印工具。所有处理均在本地浏览器完成，不需要上传图片。

功能特点
- 本地处理：无需后端接口，保护数据隐私。
- 批量操作：支持多张图片同时处理并打包下载。
- 隐藏水印：文字信息嵌入图片中，肉眼不可见。
- 水印提取：通过上传已处理的图片还原隐藏文字。

操作指南

添加水印
1. 切换到“编码 / 嵌入”面板。
2. 拖入需要处理的图片（支持多选）。
3. 在左侧输入需要隐藏的水印文字。
4. 点击保存或批量打包下载。

提取水印
1. 切换到“解码 / 提取”面板。
2. 拖入带有隐藏水印的图片。
3. 将左侧的“步长(Step)”调整为加水印时使用的数值（默认是20）。
4. 右侧画布会显示提取出的水印，点击保存即可。
